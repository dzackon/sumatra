# Autosubst 2

This directory contains a two-file subset of [Autosubst 2](<https://github.com/uds-psl/autosubst2>) (`core` and `fintype`), so that no separate installation is required. 
It is imported using:
```
From Sumatra.Autosubst Require ...
```
This naming avoids potential name clashes with other Autosubst installations.

For instructions on using Autosubst 2 generate first-order renaming, substitutions, and substitution lemmas, refer that project's [README](<https://github.com/uds-psl/autosubst2/blob/main/README.md>).
